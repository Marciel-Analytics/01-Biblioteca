# 📊 Análise de Aluguel de Casas

Este projeto foi desenvolvido durante as aulas 03 e 04, com o objetivo de aplicar conceitos de análise de dados utilizando Python e o pacote Pandas. A proposta é ajudar na escolha de imóveis com melhor custo-benefício de acordo com características específicas.

## 🎯 Objetivo

Encontrar o melhor custo-benefício em imóveis para aluguel com base em critérios definidos pelo usuário.

## 🧠 Etapas do Projeto

- **Entendimento do Negócio**
  - Meta: Achar o melhor custo-benefício para o cliente
  - Estratégia: Escolher imóveis que atendam aos critérios definidos

- **Coleta de Dados**
  - Fonte: Arquivo Excel `houses_rent.xlsx`

- **Limpeza de Dados**
  - Conversão de colunas para formatos apropriados (ex: datas, numéricos)
  - Remoção de dados inconsistentes ou ausentes

- **Exploração de Dados**
  - Visualização de métricas como valor do aluguel, localização, número de quartos, etc.

## 🛠️ Tecnologias Utilizadas

- Python
- Jupyter Notebook
- Pandas
- Excel (`.xlsx`)

   ```bash
   git clone https://github.com/seuusuario/nome-do-repositorio.git
   ```

   ```bash

   ```
3. Certifique-se de que o arquivo `houses_rent.xlsx` está na mesma pasta do notebook.
